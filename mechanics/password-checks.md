《Password》b0.85 的大多数金库输入使用同一套处理规则，但输入结果仍会随日期和几处角色线例外而变化。以下内容不会公开四次主要检定的答案。

Path P 最终流程中的密码与 D1 咖啡杯姓名使用各自独立的规则。需要逐级解谜线索时，见[密码分级提示](../guide/password-hints.md)。

::: {.pw-reading-summary}
**先看这三点**

- 普通金库输入忽略大小写与首尾空格，但内部空格、标点和拼写仍需准确。
- 有效答案还要匹配日期；D4／D6 的第一组检定还须对应当前角色线。
- Sal／Tyson 的保护只改变失败后果，不等于检定成功。
:::

## 输入如何识别

普通金库密码会：

- 忽略英文字母大小写；
- 自动删除输入前后的空格；
- 保留单词内部的空格与标点，因此拼写仍需准确。

例如，`example`、`EXAMPLE` 和 `Example` 会被视为相同输入；改变单词内部的空格或标点，则会被视为另一个字符串。

## 日期与失败结果

游戏会同时检查输入内容和当前日期。玩家实际会遇到四种结果：

::: {.password-result-table .table-responsive .table-scroll-compact}

| 输入情况 | 游戏结果 |
|---|---|
| 当前日期的正确密码 | 显示对应警告或幻象，并返回剧情 |
| 其他日期才有效的密码 | 视日期显示“时间不对”或普通错误回应 |
| 空输入 | 显示当天的空输入回应 |
| 未识别的输入 | 显示当天的错误回应 |

:::

完成一次密码检定通常只代表取得了该阶段的成功结果。之后的角色线、角色生死和其他剧情选择仍可能改变最终字母线，详见[字母线系统](../guide/path-system.md)。

## 主要输入阶段

剧情共有四次主要密码检定，第一组会根据角色线出现在 D4 或 D6。

::: {.password-check-stages-table .table-responsive .table-scroll-compact}

| 类型 | 日期 | 玩家需要知道的结果 |
|---|---:|---|
| 隐藏彩蛋输入 | D1 | 不影响正常通关 |
| 没有可接受答案 | D2 | 可以输入，但当天没有正确密码 |
| 可选彩蛋输入 | D3 | 成功后提高六名角色的好感度 |
| 主要检定，第 1 组 | D4 | 六条角色线都会到达；Roswell 线需要对应答案 |
| 主要检定，第 1 组 | D6 | 其他五条角色线在这里使用各自答案 |
| 主要检定，第 2 组 | D7 | b0.85 只接受当前答案 |
| 主要检定，第 3 组 | D10 | 通常决定继续 A/B 侧还是转入 C/D 侧；Sal 线有失败例外 |
| 不可用的旧内容 | D11 | 剧情仍提到相关单词，但没有可正常使用的密码入口 |
| 主要检定，第 4 组 | D17 | 失败后果在之后出现；Tyson 线有例外 |
| 独立最终输入 | Path P 最终流程 | 线索就在输入前，错误后会自动重试 |

:::

D1 和 D3 属于可选彩蛋，不是推进主线所需的密码。具体效果见[彩蛋与隐藏输入](../extras/easter-eggs.md)。

## D4 与 D6：必须对应当前角色线

六条角色线都会到达 D4 金库。此时只有 Roswell 线需要用到本线答案；其他五条角色线会在 D6 进行同一组检定。

D6 输入只检查单词和日期，不会阻止玩家输入另一个角色的有效答案。

因此，输入其他角色的答案时，游戏仍可能显示那名角色的警告，但当前搭档所需的结果不会生效，之后仍会进入当前角色线的失败剧情。

## Sal 与 Tyson：避开后果不等于检定成功

Sal 线在 D10 选择 **Give up** 后仍属于检定失败，只是 Sal 线剧情会阻止通常发生的 D11 灾难和 Path C/D 分流。

若要收齐画廊内容，仍需正确输入密码；成功场景会显示 Sal 的金库 CG 和一张被归入其他角色分类的相关图像。

Tyson 线在 D17 失败或选择 **Give up** 后，同样不会被视为成功，但之后的专属剧情会阻止 D19 灾难和 Path F/G 分流。

**这两种例外只改变失败的后果，不会补发成功场景或成功限定内容。**完整分流见[字母线系统](../guide/path-system.md)。

## D7：当前答案可以正常推进

b0.85 的 D7 只接受当前答案。正确输入后会正常进入完整的成功场景，并取得继续通过 D8 所需的结果。

b0.7 曾接受的另外两个单词不能推进主线，在 b0.85 中也已经不能输入成功。具体变化见[旧版本密码档案](../versions/legacy-passwords.md)。

## D11：b0.85 没有可用密码

D11 剧情仍会展示并解释一个旧版单词，部分后续对白也保留了相关痕迹，但 b0.85 的正常剧情不会开放对应的金库输入或成功场景。

因此，D11 没有可实际使用的密码，也不属于四次主要检定。旧版入口与用途见[旧版本密码档案](../versions/legacy-passwords.md#d11-%E5%8F%AF%E9%80%89%E9%87%91%E5%BA%93)。
