《Password》的核心机制之一，就是玩家必须从 Bad Ending 和剧情文本中寻找密码，再利用过去循环中的信息改变后续结果。

b0.85 中共有四个会显著影响剧情走向的关键密码，输入时间分别位于：

1. D4／D6
2. D7
3. D10
4. D17

此外，b0.85 版本中 Path P 中新增了一个难度较低的密码。D1—D3 也存在少量彩蛋输入，但它们不会影响正常剧情。

::: {.callout-important}
## 使用原则

本站默认只提供分级提示，不直接在普通攻略页面公开关键密码。

建议从一级提示开始；仍然无法找到时，再依次展开二级和三级提示。三级提示中的 `_` 代表一个被隐藏的字母。

本页的四组关键密码和 Path P 密码均为单个英文单词，不区分大小写，但拼写必须正确。
:::

## 一号关键密码

**输入时间：**

- Roswell 线：D4 下午；
- 其他角色线：D6 早晨。

**特点：**六条角色线分别对应不同密码。只有输入当前角色线对应的密码，才能正常推进剧情。

<details>
<summary><strong>一级提示</strong></summary>

每条角色线的密码都出现在对应角色的早期 Bad Ending 中。

这一组密码的设计逻辑是：玩家通常需要先经历对应的失败流程，才能从死亡或创伤剧情中取得下一次循环所需的信息。
</details>

<details>
<summary><strong>二级提示</strong></summary>

注意 Bad Ending 中被反复提到、异常强调，或者以全大写形式出现的英文单词。

这些词通常与该角色死亡或遭遇危险的直接原因有关。
</details>

<details>
<summary><strong>三级提示：字母结构</strong></summary>

- Dean：`d _ _ _ h c _ p`
- Tyson：`s _ l _ d _ r _ t y`
- Roswell：`d _ s c _ v _ r y`
- Orlando：`s _ n t _ n c _`
- Sal：`d r _ _ m _ r`
- Hoss：`h _ r _ i s m`
</details>

::: {.callout-note}
输入其他角色线对应的正确密码会提前看到那条路线对应的创伤 CG，但不会帮助当前角色线继续发展。
:::

## 二号关键密码

**输入时间：**D7 傍晚

b0.85 已经简化了这一段流程：旧版本（b0.7 及更早）中的两个假密码被删除，目前只保留唯一的正确密码。

<details>
<summary><strong>一级提示</strong></summary>

先让密码检定失败，进入对应的 Bad Ending。

关键提示出现在 Dave 与 Orlando 的对话中。
</details>

<details>
<summary><strong>二级提示</strong></summary>

重点注意 Orlando 如何描述“做出这件事需要怎样的心理状态”，以及 Dave 如何询问“是否有人对 Benson 做了某件事”。

两个句子缺失的是同一个单词。
</details>

<details>
<summary><strong>三级提示</strong></summary>

这个词可以表示一种严重的**背叛**行为。

**字母结构：**`b _ t r _ y _ l`
</details>

::: {.callout-note}
旧版本中还存在两个会被程序暂时判为正确、但最终仍然进入 Bad Ending 的假密码。相关机制已移至[旧版本密码档案](../versions/legacy-passwords.md)。
:::

## 三号关键密码

**输入时间：**D10 傍晚

<details>
<summary><strong>一级提示</strong></summary>

非 Sal 线中，密码会在 D10 与 Benson 或 Roswell 的对话里多次出现。

此前是否揭露 Oswin，会改变与 Dave 对话的人，但不会改变密码本身。
</details>

<details>
<summary><strong>二级提示</strong></summary>

这个词也可以直接概括 Path C 或 Path D 剧情中发生的惨剧。
</details>

<details>
<summary><strong>三级提示</strong></summary>

它是一个描述大规模**屠杀**的英文单词。

**字母结构：**`m _ s s _ c r _`
</details>

### Sal 线的特殊情况

Sal 线即使没有正确输入密码，也不会因此进入 Path C 或 Path D，因为 Dave 在此前已经介入了 Sal 的睡眠问题。

但是，只有正确输入密码，才能解锁 Sal 抱起 Dave 的相关 CG。因此，即使剧情能够继续，全收集玩家仍然需要完成检定。

## 四号关键密码

**输入时间：**D17 下午

<details>
<summary><strong>一级提示</strong></summary>

只需要关注 Orlando 的话。

Tyson 在这一段说出的内容并不是正确答案的来源。
</details>

<details>
<summary><strong>二级提示</strong></summary>

这个词与 Tyson 失控后的形象有关，也被用于相关创伤 CG 的文件名。

输入 `monster` 或 `feral` 时，Thanatos 会提示玩家已经非常接近正确答案了。
</details>

<details>
<summary><strong>三级提示</strong></summary>

**字母结构：**`w _ r _ w _ l f`

答案是一个用于描述**狼人**形象的英文单词。
</details>

### Tyson 线的特殊情况

Tyson 线中，即使没有正确输入密码，也不会进入 Path F 或 Path G。

原因是此线路中 Dave 与 Tyson 的关系更加亲密，Tyson 已经主动告诉 Dave 自己近期的睡眠异常，因此 Dave 可以在没有金库提示的情况下发现床下的噪音装置。

## Path P 密码

b0.85 在 Path P 中增加了一个新密码。其难度明显低于前四个关键密码，提示会在输入环节之前直接出现。

<details>
<summary><strong>一级提示</strong></summary>

仔细阅读 Thanatos 在输入密码前说出的内容。
</details>

<details>
<summary><strong>二和三级提示</strong></summary>

这个词表示“神化”或“升格为神”的过程。

无需从其他 Path 或 Bad Ending 中寻找。
</details>

## 彩蛋密码与特殊输入

D1—D3 存在一些正常剧情不会提示的彩蛋密码或特殊输入。它们不影响路线，也不是通关所必需的内容。

相关内容包括：

- D1 奶茶杯名字彩蛋；
- D1—D3 的非强制密码；
- 已被删除但仍残留在代码中的旧密码；
- 输入错误日期密码时的特殊回应。

这些内容单独整理在：

[彩蛋密码与特殊输入](../extras/easter-eggs.md)

## 仍然无法解决？

建议依次检查：

1. 是否处于正确的日期；
2. 是否进入了对应角色线；
3. 是否把空格、连字符或单词拼写输入错误；
4. 当前版本是否确实为 b0.85；
5. 是否参考了只适用于 b0.7 或更早版本的旧攻略。

如果游戏流程与本页描述仍然不一致，可以结合当前角色线、日期、存档显示的 Path 和最近一次选择进行排查。
