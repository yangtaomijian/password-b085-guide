《Password》中存在两套相互独立但会彼此影响的路线系统：

- **角色线**在 D4 选择搭档后确定，包括 Dean、Tyson、Roswell、Orlando、Hoss 和 Sal；
- **字母线**主要由 D8 的选择，以及 D10、D17 的密码检定决定。

选择某条角色线，并不等于自动进入某个字母线。角色线主要决定同行角色和具体剧情，而字母线决定后半段主线的发展方向。

::: {.callout-warning}
## 路线剧透

本页会直接说明 Path A—G 和 Path P 的进入逻辑，但不会公开密码答案。
:::

## 基础分流：Path A—D

D8 中是否向其他人揭露 Oswin，是字母线的第一个分歧。之后，D10 的密码检定会确定基础线路。

| D8 的选择 | D10 检定 | 基础线路|
|---|---|---|
| 隐瞒 Oswin | 成功 | Path A |
| 揭露 Oswin | 成功 | Path B |
| 隐瞒 Oswin | 失败 | Path C |
| 揭露 Oswin | 失败 | Path D |

因此：

- **A／C**来自隐瞒 Oswin；
- **B／D**来自揭露 Oswin；
- D10 是否通过密码检定，决定进入前者还是后者。

### Sal 线的特殊情况

Sal 线不会因为 D10 密码错误而进入 Path C 或 Path D。

不过，正确输入密码仍然关系到部分 CG 解锁，因此全收集玩家仍应完成该检定。

## 后续分流：Path E—G

Path C 和 Path D 会根据之后与 Sal 及磨坊事件有关的选择，继续保持原 Path，或者转入 Path E。

Path A 和 Path B 则会继续推进到 D17，并接受第二次关键路线检定。

| 当前 Path | D17 检定成功 | D17 检定失败 |
|---|---|---|
| Path A | 保持 Path A | 进入 Path F |
| Path B | 保持 Path B | 进入 Path G |

D17 检定失败后，个别选择（如“独自离开”）还可能直接进入 Bad Ending，而不是继续完成 Path F 或 Path G。

### Tyson 线的特殊情况

Tyson 线不会因 D17 密码检定失败而转入 Path F 或 Path G：

- 原本处于 Path A 时，继续保持 Path A；
- 原本处于 Path B 时，继续完成 Path B。

这一豁免不会改变 D8 和 D10 已经确定的基础方向。

## Path P

Path P 不是从前期单独选择的路线，而是 **Path A 的最终收集分支**。

进入 Path P 需要：

1. 先保持在 Path A；
2. 推进到最终奖牌检定；
3. 已经收集全部十二枚奖牌。

如果奖牌没有集齐，则进入普通 Path A 结局；奖牌全部收集后，才会转入 Path P。

具体收集方法见[十二枚奖牌收集指南](../collectibles/medals.md)。

## 各 Path 简表

| Path | 核心进入条件 |
|---|---|
| A | D8 隐瞒 Oswin；通过 D10 和 D17 的路线检定 |
| B | D8 揭露 Oswin；通过 D10 和 D17 的路线检定 |
| C | D8 隐瞒 Oswin；D10 检定失败 |
| D | D8 揭露 Oswin；D10 检定失败 |
| E | 从 Path C 或 D 经后续选择进入 |
| F | 从 Path A 出发，D17 检定失败 |
| G | 从 Path B 出发，D17 检定失败 |
| P | 完成 Path A 主干，并在最终检定前集齐十二枚奖牌 |

表中的检定成功也包括对应角色线的特殊豁免：

- Sal 线豁免 D10；
- Tyson 线豁免 D17。
