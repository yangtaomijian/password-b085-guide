本页汇总《Password》b0.85 中最常见的问题。这里只提供简短结论；详细条件和代码机制请进入对应专题页面查看。

本站以 **b0.85** 为核心版本。旧版攻略中的密码、路线和剧情入口不一定适用于当前最新版本。

## 路线与 Path

### 角色线和字母线是同一回事吗？

不是。角色线在 D4 选择搭档后确定；字母线主要由 D8 的选择和 D10、D17 的检定决定。

选择某名角色不会自动固定为某个字母线，两者逻辑上没有直接关系。详见[剧情线路总览](route-overview.md)和[字母线系统](path-system.md)。

### 如何进入 Path P？

Path P 是 Path A 的最终收集分支：保持在 Path A，推进到最终检定，并确保十二枚奖牌已经全部写入。

Path B 可以取得部分必要奖牌，但最终必须在一次 Path A 流程中推进到奖牌检定。奖牌会跨存档和周目保留，因此可以先完成 Path B，再读取较早存档或开始新的 Path A 流程。

详见[十二枚奖牌收集指南](../collectibles/medals.md)。

### 为什么存档显示的 Path 与选择不一致？

存档显示会根据 Dave 当时已经知道的信息更新，因此可能晚于代码中的实际分支变化。短暂显示旧路线不一定表示此前的选择没有生效。

## 密码

### 密码输入有什么格式要求？

密码不区分大小写，首尾空格会被删除，但拼写和单词内部的空格必须正确。密码还必须在对应日期输入。

如果正确密码没有反应或者报错，请检查当前日期、角色线、拼写、内部空格、游戏版本，以及参考的攻略是否属于旧版本。

### 找不到密码怎么办？

本站按一级、二级和三级逐步提供提示，三级提示包含词义和字母结构。见[密码分级提示](password-hints.md)。

### 为什么 Sal 的 D10／Tyson 的 D17 检定失败后仍能继续？

Sal 线可以绕过 D10 的路线失败结果，但正确输入仍关系到一张 CG。

Tyson 线可以绕过 D17 的路线失败结果，不会因此转入 Path F 或 Path G。

## 奖牌与 Path P

### 奖牌必须在一个周目中收齐吗？

不需要。按照单一角色线和单一字母线连续推进，无法一次取得全部十二枚；奖牌通过持久变量跨存档和周目累计，因此不需要在单次流程中收齐。

### 为什么剧情中发现了奖牌，却没有计入收集？

剧情发现时间不一定等于代码写入时间。例如水瓶座（Aquarius）和金牛座（Taurus）要到 D16 的奖牌盘点场景才写入持久变量。

具体节点见[十二枚奖牌收集指南](../collectibles/medals.md)。

### 如何确认缺少哪枚奖牌？

查看 Compendium 中的十二个星座 Lore。Lore 与 Path P 最终检定读取同一组持久变量，因此锁定的 Lore 通常就是尚未完成写入的奖牌。

### 删除普通存档会清除奖牌吗？

通常不会。普通存档与 `persistent` 持久数据分开保存。

但清除整个用户数据目录、重装后未保留数据，或跨设备迁移不完整，都可能使奖牌记录丢失。详见[奖牌持久化与最终检定](../mechanics/medal-persistence.md)。

## CG 与好感度

### 如何定位画廊中缺失的 CG？

画廊按从左到右、从上到下排列，每行四张。可以根据游戏内画廊展示出的行和列对照[CG 画廊查漏索引](../collectibles/gallery.md)。

通常只要脚本实际显示了图片，就会写入已见记录，不需要继续推进到当天结束。部分脚本图片没有登记进画廊，因此不会增加 100 张完成统计。

### Hoss 的两张亲吻 CG 如何解锁？

- `hosskiss`：Hoss 线 D8 前达到 `lionlove >= 12`；
- `hosskiss2`：D19 前达到 `lionlove >= 20`，并接受关系发展。

完整加点见[好感度机制与加点](../mechanics/affection.md)。

### 好感度会决定能否通关吗？

通常不会。好感度主要改变心理描写、亲密互动、关系确认文本和少数 CG；字母线主要由剧情选择和密码检定决定。

当前整理的 b0.85 正常剧情中没有发现明确的好感度减分项。

- 需要查询加点选项时，见[好感度机制与加点](../mechanics/affection.md)；
- 需要确认达到阈值后具体改变哪些对话和关系分支时，见[好感度检定与剧情文本差异](../mechanics/affection-differences.md)。

## Compendium

### 星座 Lore 和奖牌是两套收集吗？

不是。十二个星座 Lore 直接读取十二枚奖牌的持久变量，并与 Path P 的最终检定共享同一套状态。

### 为什么某个 Cast File 仍然锁定？

不同角色档案可能要求特定角色线、日期、Path、存活状态或代码写入节点。请根据游戏内固定顺序对照[Compendium 解锁索引](../collectibles/compendium.md)。

### 为什么下一项 Additional Scene 没有开放？

优先确认上一段 Epilogue 是否真正播放到结尾，以及当前角色的 Cast File 是否已经解锁。中途退出回放可能使完成变量尚未写入。

## 版本与旧攻略

### 为什么旧路线图或旧密码与当前游戏不同？

《Password》在不同版本中调整过路线选择、密码、CG 和代码入口。旧版资料只能作为历史档案，不应直接套用于 b0.85 版本。

相关资料见：

- [b0.85 版本主要变化](../versions/b085-changes.md)
- [旧版本线路档案](../versions/legacy-routes.md)
- [旧版本密码档案](../versions/legacy-passwords.md)
- [旧版本机制档案](../versions/legacy-mechanics.md)

### 如何确认自己的游戏版本？

优先查看游戏主菜单或 About／版本信息页面。如果密码日期、路线结果或界面内容大量与本站不一致，可能正在使用不同版本。

## 仍然无法解决？

排查时建议记录：

1. 游戏版本；
2. 当前角色线；
3. 当前日期；
4. 存档显示的字母线；
5. D8 是否揭露 Oswin；
6. 最近一次关键检定是否成功；
7. 缺失的奖牌、CG 或 Compendium 条目；
8. 是否使用旧存档或迁移过用户数据。

这些信息通常足以判断问题属于路线条件、密码日期、持久变量还是版本差异。
