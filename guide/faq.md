## 角色线与字母线

### 角色线和字母线是同一回事吗？

不是。D4 的搭档选择决定角色线；之后的剧情选择、密码检定和角色生死状态决定字母线。两套系统会同时持续存在，但作用不同。

详见[剧情线路总览](route-overview.md)和[字母线系统](path-system.md)。

### 如何进入 Path P？

在游戏已经记录全部十二枚奖牌后，再完成一次 Path A。奖牌进度会跨存档和周目保留，但最终奖牌检定只会在 Path A 主结局之后执行。

如果过早完成了 Path A，可以先取得缺少的奖牌，再重新完成 Path A。详见[十二枚奖牌收集指南](../collectibles/medals.md)。

### 为什么存档显示的 Path 与我的选择不一致？

存档槽显示的是创建该存档时，游戏已经正式写入的 Path。部分选择会先改变隐藏剧情状态，之后才更新显示的 Path。

Sal 线在 D10 放弃密码检定后，也可能暂时显示 `Path C`，但该角色线的特殊豁免仍会让剧情留在共同的 Path A/B 一侧。这是显示状态不一致，不代表真正进入了通常的 Path C 剧情。

详见[字母线系统](path-system.md)。

## 密码

### 金库密码有什么输入格式要求？

密码输入不区分大小写，首尾空格会被自动去除；但拼写、标点、单词内部空格和输入日期仍必须正确。

第一组关键密码还取决于当前角色线。需要逐级线索时，见[密码分级提示](password-hints.md)。

### 为什么 Sal 线的 D10 或 Tyson 线的 D17 检定失败后，剧情仍能继续？

这两条角色线都有特殊保护机制，可以阻止密码失败通常造成的后续灾难和字母线分流。

但**检定失败不会被当作成功**，成功分支中的警告内容和部分收集内容仍然会错过。完整后果见[字母线系统](path-system.md)。

## 奖牌与持久进度

### 十二枚奖牌必须在同一个周目中收齐吗？

不需要。奖牌使用持久变量记录，会跨存档和周目累计。由于其中四枚只会在特定角色线取得，因此完成全部收集必然需要多个角色线。

详见[十二枚奖牌收集指南](../collectibles/medals.md)。

### 为什么剧情中已经发现奖牌，收集状态仍然显示缺失？

部分奖牌在剧情中出现后，不会立刻写入持久记录。例如 Aquarius 和 Taurus 要到 D16 的奖牌盘点场景才正式记录。

如果使用锁定的 Lore 判断奖牌是否缺失，应先重启游戏，排除 Compendium 尚未刷新当前会话解锁状态的情况。详见[奖牌持久化与最终检定](../mechanics/medal-persistence.md)。

### 删除普通存档会清除奖牌吗？

不会。十二枚奖牌的状态与普通剧情存档分开保存。读取或删除普通存档，不会回滚已经写入的奖牌标记。

但清除全部游戏数据，或迁移到其他设备时没有完整保留用户数据，仍可能导致记录丢失。详见[奖牌持久化与最终检定](../mechanics/medal-persistence.md)。

## Gallery、好感度与 Compendium

### 如何定位 Gallery 中缺失的 CG？

使用[CG Gallery 查漏索引](../collectibles/gallery.md)，可以按 CG ID、触发条件、类别或网格位置检索 72 个 Memories 条目和 28 个 Trauma 条目。

并非所有剧情图片都登记在 Gallery 中；Gallery 显示的完成数量也可能需要重启游戏后才刷新。

### 好感度会决定能否通关吗？

不会。好感度不决定字母线、密码是否成功、角色存活、奖牌收集或 Path P。

它主要影响对话、亲密选项、部分 CG 和 D19 的关系结果。详见[好感度机制与加点](../mechanics/affection.md)。

### 为什么 Compendium 条目仍然锁定？

先重启游戏，因为当前会话中刚获得的解锁状态可能尚未显示在 Compendium 中。

如果重启后仍然锁定，请在[Compendium 解锁索引](../collectibles/compendium.md)中核对该条目的要求。对于 Epilogue，还要确认上一段 Replay 已经播放到结尾，而不是中途使用 **End Replay** 退出。

## 界面与版本

### 为什么主菜单角色会改变或消失？

主菜单会读取最新存档中的角色线和 Path。

如果最新存档没有有效的角色线状态，主菜单会退回显示 Dave；Path E 使用空背景。Path A 后期的部分场景还会暂时清除角色线标记，因此主菜单可能发生变化，直到后续存档重新写入或替换这些状态。

### 为什么游戏流程与本站描述不一致？

本站只记录 Password b0.85。如果路线、密码场景或 CG 位置存在明显差异，请先检查游戏版本和下载来源；为旧版本编写的资料可能不适用于 b0.85。

## 仍然无法解决？

寻求帮助时，建议同时提供：

1. 游戏版本和当前日期；
2. 相关存档显示的角色线与 Path；
3. D10 或 D17 的相关检定是否成功；
4. 缺失项目的准确名称，例如奖牌、CG ID、Cast File、Lore 或 Additional Scene。

报告 Gallery 或 Compendium 显示问题前，请先重启一次游戏。对于 Additional Scene，还要确认前一段 Replay 已经完整播放到结尾。
