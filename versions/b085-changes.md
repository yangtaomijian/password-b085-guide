本页整理《Password》b0.85 相较 b0.7 及更早版本的主要变化。

本页只收录旧攻略专栏已经明确记录的变化，可能存在错误或遗漏；部分旧密码和剧情入口在 b0.85 中已经失效。

> **资料范围：**这不是作者发布的完整官方更新日志。没有被现有资料明确记录的细节，本页不作补充推测。

## 变化概览

::: {.b085-change-overview-table}

| 类型 | b0.85 的主要变化 |
|---|---|
| 新增内容 | Compendium、Additional Scenes、角色 Epilogue、Path P 新密码 |
| 流程简化 | Orlando 与 Roswell 的前期选择减少 |
| 删除内容 | D6 离开宅邸、D7 两个假密码、D8 Oswin 问答、D11 可选密码 |
| 剧情与资源 | Path P 文本调整、Tyson 相关 CG 重绘、Dean 旧 CG 删除 |

:::

## Compendium 与附加回放

b0.85 新增 Compendium，并分为：

- Cast Files；
- Additional Scenes；
- Lore。

Lore 直接显示十二枚奖牌的解锁状态，便于查找 Path P 所缺的奖牌。

旧版本中只能在特定流程观看的 Dave's Demise 和 Roswell's Attempt，也被加入 Additional Scenes，可以在解锁后反复回放。

b0.85 还加入了接续 Path P 的七段角色 Epilogue。具体顺序和解锁条件见[Compendium 解锁索引](../collectibles/compendium.md)。

## 存档界面变化

D4 确定搭档后，存档界面右上角会显示对应角色的像素头像，用于识别当前角色线。

这一显示代表角色线，不等同于字母线。

## 前期路线简化

| 旧版流程 | b0.85 |
|---|---|
| Orlando 线 D6 需要处理下午和晚上的两次跟踪选择 | 删除晚上的第二次选择，只保留下午的主要判断 |
| Roswell 线存在多次救援相关选择 | 简化为一次主要救援选择 |
| D6 晚上可以选择离开宅邸 | 该选择及对应 Bad Ending 删除 |
| D7 使用一个真密码和两个假密码 | 两个假密码剧情删除，只保留唯一有效答案 |
| D8 晚上可以自由向 Oswin 提问 | 整个问答环节删除 |
| 非首次 Path A 的 D11 可以前往金库并输入可选密码 | 正常输入入口删除 |

D7 真正能够推进主线的密码没有改变，但旧版通过两个假密码快速显示相关 Trauma CG 的方法已经失效。

旧密码的完整历史见[旧版本密码档案](legacy-passwords.md)，D8 问答与其他机制残留见[旧版本机制档案](legacy-mechanics.md)。

## Path P 调整

b0.85 在 Path P 中新增了一个难度较低的密码，提示会在输入前直接出现在剧情中。

现有资料还明确记录了以下变化：

- 现在由 Dave 亲自打开金库，而不是 Oswin；
- Tyson 与 Dave 的谈心内容有所调整；
- Path P 的多处文本和事件顺序经过修改。

密码提示见[密码分级提示](../guide/password-hints.md)。

## Tyson 与 Dave 的内容调整

b0.85 中，Tyson 会使用 `Stripes` 称呼 Dave，可理解为对应 Dave 条纹外貌的昵称。

现有资料还记录了两张 Tyson 与 Dave 的 CG 重绘：

- Tyson 开车、Dave 坐在旁边的场景；
- Tyson 与 Dave 一起看电影的场景。

前者可在部分角色线的 D6 Bad Ending 中看到，后者位于 Tyson 线前期。

## Dean 线调整

b0.85 修改了 D19 之前的部分 Dean 线内容。

与 Dean 有关的四张旧成人 CG 已从当前游戏文件中移除：

- b0.7 中，这些图片虽然已经不在正常剧情中显示，但资源文件仍然存在；
- b0.85 中，相关图片已经从游戏文件中删除；
- 它们不属于当前画廊的 100 张完成统计。

## 使用旧攻略时

出现以下内容时，通常说明攻略适用于 b0.7 或更早版本：

- D6 可以选择离开宅邸；
- D7 要依次尝试两个假密码；
- D8 可以自由向 Oswin 提问；
- D11 可以前往金库输入 `METEMPSYCHOSIS`；
- Path A 的特殊剧情只能在正常流程中观看一次；
- Dean 的四张旧成人 CG 仍存在于游戏资源中。

当前路线、密码和收集条件应以 b0.85 页面为准。
