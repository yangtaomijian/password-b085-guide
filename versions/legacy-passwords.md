本页记录 *Password* b0.7 中存在、但已经无法通过 b0.85 正常流程使用的密码机制。

主要包括：

- b0.7 在 D7 可接受的三个金库输入；
- D11 的可选 `METEMPSYCHOSIS` 金库流程。

这是历史档案，不是当前版本的密码攻略。

::: {.callout-warning}
## 不适用于 b0.85

`PEACEKEEPER` 和 `ARBITER` 已不能作为 b0.85 的 D7 输入；D11 可选金库也不再拥有正常剧情入口和完整成功实现。

当前版本的密码提示见[密码分级提示](../guide/password-hints.md)。
:::

## b0.7 的 D7 三个可接受输入

b0.7 的金库在 D7 会接受三个不同的单词。三者都能够通过输入检定、播放成功反馈，并进入各自的预警场景。

但它们对第二天主线的作用并不相同。

::: {.table-responsive .table-scroll-medium}
| D7 输入 | b0.7 中的技术作用 | 立即显示的预警 | 主线结果 |
|---|---|---|---|
| `PEACEKEEPER` | 可接受但不推进的替代输入 | Orlando 中枪 | 无法通过 D8 的主门槛 |
| `ARBITER` | 可接受但不推进的替代输入 | Dean 与 Tyson 抢夺手枪 | 无法通过 D8 的主门槛 |
| 当前 D7 答案 | 主门槛答案 | Benson 死亡预警 | 写入通过 D8 主门槛所需的状态 |
:::

因此，前两个单词并不是程序意义上的“无效密码”或“假密码”。金库会正式接受它们，并写入各自的变量。

它们之所以不能推进主线，是因为 D8 只检查当前主门槛答案对应的状态。输入任意一个旧替代词，仍然会进入 Benson 的 Bad Ending 时间线。

## 旧版提示结构如何运作

b0.7 的 D7 解谜比当前版本更加迂回，但源码并没有强制玩家依次完成三个密码。

普通 D7 失败会进入一段 Bad Ending，并在同一流程中提供两个旧替代输入的线索。玩家随后可以直接输入 `PEACEKEEPER` 或 `ARBITER` 中的任意一个；游戏并不要求先完成其中一个，才能输入另一个。

两个替代输入最终会汇合到同一段后续调查流程。该公共分支再提供真正主门槛答案的线索。

最准确的结构是：

```text
普通 D7 失败
→ 同时获得两个旧替代输入的线索

任意一个旧替代输入
→ 进入公共调查分支
→ 获得主门槛答案的线索
```

旧攻略可能会按照推荐发现顺序排列三个单词，但该顺序并不是由 persistent 变量或金库 dispatcher 强制控制的。

## Trauma CG 与画廊解锁

三个 D7 输入会立即显示不同的预警画面：

::: {.trauma-warning-table .table-responsive}
| 输入 | 显示的预警画面 |
|---|---|
| `PEACEKEEPER` | Orlando 中枪 |
| `ARBITER` | Dean 与 Tyson 抢夺手枪 |
| 当前 D7 答案 | Benson 死亡预警 |
:::

这些 image ID 会通过 Ren'Py 的 seen-image 机制注册进画廊。正常游玩时，只要实际显示相应图片，就会满足该图片的画廊解锁条件。

因此，b0.7 的两个旧替代输入曾提供快速显示 Orlando 和 Dean/Tyson 两张 Trauma CG 的方法。b0.85 不再接受这两个单词，所以这条捷径已经失效。

当前版本的 D8 强制 Bad Ending 仍会在正常失败流程中显示旧版的相关 Trauma CG。

当前画廊结构见[CG 画廊查漏索引](../collectibles/gallery.md)。

## D11 可选金库

b0.7 还包含一个非强制的 D11 金库输入：`METEMPSYCHOSIS`。

它与四个主要密码检定不同，不是继续主线所必需的密码，而是用于开启另一组实验室文本和后续条件对白的隐藏分支。

### 何时出现

正常入口要求同时满足：

```renpy
persistent.metempsychosis_check == True
BensonAround == True
```

其中 persistent 状态会在玩家已经完整经历过一次对应的 Oswin 存活 D11 实验室流程后写入。

在之后再次进入符合条件的 A/B 侧 D11 流程时，玩家可以看到额外选择：

```text
Visit the Vault.
Stay here.
```

选择 `Visit the Vault.` 会打开密码输入；选择 `Stay here.` 则直接继续剧情。

因为入口依赖 persistent 状态，所以该解锁会在不同存档和角色线之间共享。单纯开始 New Game 不会恢复第一次进入该段剧情时的状态。

### 提示与成功效果

这个单词会在此前的实验室剧情中直接出现，因此后续输入更接近对旧时间线信息的记忆检查，而不是强制解谜。

成功输入后会写入 `METEMPSYCHOSIS = True`。这是当前周目的普通变量，不是新的 persistent 完成标记。

它会改变 D11 实验室段落及之后若干条件对白，但不会直接改变：

- 当前角色线；
- 当前字母线；
- 奖牌完成状态；
- 最终结局分类。

## b0.85 中的 D11 残留

b0.85 仍保留旧实现的若干部件：

- 可识别的密码字符串及其 D11 日期映射；
- D11 的错误输入和空输入处理；
- `METEMPSYCHOSIS` 变量；
- 后续仍会读取该变量的条件对白。

但当前版本已经缺少一条完整、可正常游玩的进入路径：

- 正常 D11 剧情不会打开 `vaultInput`；
- 旧成功 label 已不存在；
- b0.85 的正常剧情不会写入 `METEMPSYCHOSIS = True`；
- 用于开放旧入口的 persistent 准备流程也无法通过正常流程完整建立。

因此，它最准确的分类是**不完整的旧代码残留**，而不是仍然隐藏在当前版本中的可用密码。

对于由 b0.85 正常新建的周目，保留下来的条件对白会使用默认的 `False` 分支。

## Path P 新输入

b0.7 在 Path P 后段没有当前版本的独立文字输入。

b0.85 在原有 Path A 结局、十二枚奖牌检查以及进入 Path P 之后，新增了一次强制输入。它发生在 Path P 内部，不决定玩家是否能够进入 Path P。

当前提示见[密码分级提示](../guide/password-hints.md)，更完整的版本变化背景见[b0.85 版本主要变化](b085-changes.md)。
