# Password b0.85 中文攻略与机制资料库

《Password》b0.85 的非官方中文攻略网站，整理剧情路线、密码提示、奖牌、CG、Compendium、好感度及相关机制。

## 内容范围

- 剧情线路与字母线系统
- 分级密码提示
- 十二枚奖牌与 Path P
- CG 画廊排列、触发节点与检索工具
- Compendium 解锁条件
- 好感度机制
- b0.85 与旧版本机制整理

## 说明

本项目为非官方玩家资料，与游戏作者及发行平台无隶属关系。

仓库不包含游戏本体、完整脚本、提取后的 CG 或其他未经授权的游戏资源。游戏名称、角色和原始素材的相关权利归原作者所有。

攻略内容以 b0.85 为基准，包含大量剧情与结局剧透。

## 官方入口

- 游戏 itch.io：https://passwordvn.itch.io/password
- 作者 Patreon：https://www.patreon.com/PASSWORDVN

## 本地构建

需要安装 Quarto。

预览网站：

    quarto preview

完整渲染：

    quarto render

生成的网站位于 `_site/`。
